## 📌 Executive Summary / 报告概述

The **Global Supply Chain & Logistics Industry Intelligence Research Dashboard (2026)** is an enterprise-grade, full-stack intelligence platform built for C-level supply chain executives, global freight forwarders, trade compliance officers, and logistics analysts.

Synthesizing macro geopolitical shifts (**Nearshoring 2.0 in Mexico**, **EU CSDDD ESG mandatory penalty enforcement**, **Red Sea / Cape of Good Hope maritime rerouting**), multi-period quarterly and half-year report windows (**2026 H1, Q1, Q2, 2025 H2, 2025 FY**), real-time ocean container spot rates, and **Gemini 2.5 Search Grounded RAG**, this interactive dashboard delivers actionable, data-backed insights across 7 core global industry verticals.

**2026年全球供应链与跨境物流行业研究报告工作台** 是面向企业高管、跨境物流专家与供应链战略规划者的全栈行业情报平台。系统紧扣2026年地缘政治常态化（中墨贸易通道‘近岸外包2.0’、欧盟CSDDD环境与人权尽职调查硬性惩罚、红海绕行好望角常态化），支持**多周期报告窗口动态切换 (2026 H1 / Q1 / Q2 / 2025 H2 / FY)**、**实时4秒运价与压力指数流 (Telemetry MUX)** 以及 **Gemini 2.5 联网检索增强 (RAG)** 智能问答助手，提供全景式的决策支持。

## 🌟 Key Features / 核心功能

### 📅 1. Multi-Period Reporting Window Switcher / 动态报告期窗口切换
- **Quarterly & Half-Year Granularity**: Toggle seamlessly between **2026 H1** (2026年上半年), **2026 Q1** (2026年第1季度), **2026 Q2** (2026年第2季度), **2025 H2** (2025年下半年), and **2025 FY** (2025年全年).
- **Instant Metric Synchronization**: Switching period automatically re-aligns Executive Summaries, World Container Index (WCI) benchmarks, SCSI stress indices, Recharts rate trendlines, air/ocean cargo volumes, and smart tech adoption metrics.
- **Period-Aware AI Grounding**: The Gemini RAG assistant automatically contextualizes queries based on the currently selected reporting period window.

### 🛰️ 2. Real-Time Telemetry MUX Ticker / 4秒实时运价与压力流
- **Live Spot Rate Monitoring**: 4-second ticker tracking global container indices (WCI Transpacific/Asia-Europe spot rates calibrated to selected reporting period baselines), AI decision synchronization rates, verified ESG carbon proof rates, and the Supply Chain Stress Index (SCSI).
- **Interactive MUX Controls**: Pause/Resume streaming, forced cloud-lightning telemetry pull, latency monitoring (ms), and server clock synchronization.

### 📊 3. Multimodal Logistics Performance Analytics / 多维物流履约与运费大盘
- **Ocean Freight Benchmarks**: Multi-year interactive rate curves across key routes (Transpacific, Asia-Europe, Transatlantic, Latin America).
- **Air Cargo & Cross-Border Yields**: Air cargo growth vs. ocean freight growth comparative charts powered by Recharts with dynamic period scaling.
- **Smart Tech Adoption Index**: Longitudinal tracking of Agentic AI, Autonomous Transport, IoT Cold-Chain, and Digital Customs Adoption.

### 🏬 4. Sector Deep Dives (7 Verticals) / 7大行业专项洞察
Comprehensive operational metrics, pain points, lead-time trend indicators, C-level tactical recommendations, and compliance checklists for:
1. 🚗 **Automotive & Mobility** (汽车与移动出行)
2. 💻 **Semiconductor & Consumer Electronics** (半导体与电子信息)
3. ⚡ **Renewable Energy & Battery Storage** (新能源与电池储能)
4. 💊 **Pharma & Life Sciences** (医疗医药与生命科学)
5. 📦 **FMCG & Retail** (快速消费品与现代零售)
6. 🏭 **Industrial Equipment & Heavy Machinery** (高端装备与工业设备)
7. 👗 **Cross-Border E-Commerce** (跨境电商与快时尚)

### 🤖 5. Gemini 2.5 Search Grounded RAG Assistant / 智能体检索分析助手
- **Server-Side Key Protection**: Secure Express proxy endpoint (`/api/analyze`) isolating `GEMINI_API_KEY`.
- **Google Search Grounding**: Leverages `@google/genai` with `googleSearch` tool for real-time web citations.
- **Preset Industry Prompts**: One-click deep dive queries on Sino-Mexican corridors, CSDDD audits, Red Sea parts transit, and Agentic AI procurement.

### 📖 6. In-App Interactive README Preview Modal / 应用内交互式文档查看器

## 🔒 Security & Privacy Protection / 安全与隐私保护

> [!IMPORTANT]
> **Account & Data Safety Guarantee / 账号与数据安全保障**
>
> 1. **Zero Secret Leakage**: `GEMINI_API_KEY` and all sensitive credentials are kept strictly server-side in `process.env`. They are **NEVER** exposed to client-side code, browser bundles, or public repositories.
> 2. **No `VITE_` Secrets**: API keys are not prefixed with `VITE_` to ensure Vite does not bundle secret keys into static frontend assets.
> 3. **API Proxy Encapsulation**: All AI queries go through the `/api/analyze` Express server proxy, which sanitizes inputs and hides backend architecture.
> 4. **No Personal Data Storage**: The application operates without collecting or storing personal user data, passwords, or personal account identifiers.
> 5. **Safe Environment Templates**: `.env.example` documents environment variable requirements using placeholder strings without hardcoding private tokens.

## 🚀 Quick Start Guide / 快速启动指南

### 1. Prerequisites / 前置条件
- **Node.js**: v20.0.0 or higher
- **npm**: Package manager
- **Gemini API Key**: Obtain a key from [Google AI Studio](https://aistudio.google.com/)

### 2. Installation / 安装依赖

```bash
# Clone repository
git clone https://github.com/SummerPapaya/Supply-Chain-Industry-Research.git
cd Supply-Chain-Industry-Research

# Install dependencies
npm install
```

### 3. Environment Setup / 配置环境变量

Copy `.env.example` to `.env` and configure your secret API key:

```bash
cp .env.example .env
```

Edit `.env`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Running Development Server / 启动开发服务器

```bash
npm run dev
```
Open your browser at `http://localhost:3000` to access the live interactive dashboard.

### 5. Building for Production / 编译部署

```bash
# Compile client assets with Vite & bundle server with esbuild
npm run build

# Launch production server
npm start
```

## 🔌 API Reference / API 接口说明

### 1. `POST /api/analyze`

Executes server-side Gemini 2.5 Flash query with active Google Search Grounding to return live supply chain research insights and source citations contextualized by reporting period.

#### Request Header
`Content-Type: application/json`

#### Request Body
```json
{
  "query": "分析红海绕行对汽车零部件及运价的最新影响",
  "section": "航运大通道",
  "period": "2026_H1"
}
```

#### Response Payload
```json
{
  "text": "### 2026年上半年红海绕行好望角对汽车供应链定量评估\n\n受运力绕行影响，中欧航线集装箱轮转效率下降约18-22%...",
  "sources": [
    {
      "title": "Global Shipping Line Detour Metrics 2026 H1",
      "uri": "https://example.com/shipping-report-2026"
    }
  ]
}
```

### 2. `GET /README.md`

Serves the current `README.md` markdown file for rendering inside the in-app interactive documentation modal.
